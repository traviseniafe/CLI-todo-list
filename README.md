# todo-cli

A small command-line to-do list written in Python. Tasks are saved to a local `tasks.json` file so they're still there next time you run it.

**Status:** in progress (v0.1, basic features working)

## Run it

```
Run with python todo.py (Windows) or python3 todo.py (Mac/Linux)
```

Requires Python 3.8 or newer. No extra packages needed.

## What it does

- Show all tasks with a done / not-done checkbox
- Add a task
- Mark a task as done
- Delete a task
- Saves automatically after every action
